🔗 Proxy API Endpoints

Base URL: http://localhost:3001

GET Proxy Status
/api/proxy/status

Returns the status of all proxy services including Decodo, message queue, and monitoring.

GET Monitoring Metrics
/api/proxy/metrics?limit=5

Returns historical monitoring metrics and performance data.

GET Active Alerts
/api/proxy/alerts

Returns active monitoring alerts and their severity levels.

GET Proxy Mappings
/api/proxy/mappings?limit=10

Returns proxy-device mappings and their current status.

GET Queue Status
/api/proxy/queue/{deviceId}

Returns message queue status for a specific device.

🔧 Quick Fixes

❌ Error: "Cannot GET /api/api/proxy/status"

Problem: Double /api in URL

Solution: Use /api/proxy/status instead of /api/api/proxy/status

🔐 Error: "No token, authorization denied"

Problem: Missing authentication

Solution: Login first using the form above, then test endpoints
